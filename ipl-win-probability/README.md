IPL Win Probability Prediction System

Overview

The IPL Win Probability Prediction System is a machine learning project that predicts the probability of a team winning an Indian Premier League (IPL) cricket match based on match conditions.

Features

- Predicts the probability of winning for the batting and bowling teams.
- Uses a trained machine learning model.
- Provides a user interface built with Streamlit.
- Displays predictions based on match inputs.

Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Machine Learning

Project Structure

- "app.py" – Main Streamlit application.
- "pipe.pkl" – Saved machine learning pipeline.

Installation and Usage

1. Install Python on your system.

2. Clone or download this repository.

3. Open a terminal in the project folder.

4. Install the required dependencies:
   
   "pip install streamlit pandas scikit-learn"

5. Run the application:
   
   "streamlit run app.py"
